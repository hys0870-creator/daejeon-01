## 5. 지켜야 할 규칙
**말투·형식**
- 사용자에게는 쉬운 말로 설명한다 (터미널 용어는 풀어서). 직접 해야 하는 일은 한 번에 하나씩, 클릭할 곳까지 알려 준다.
- 사용자에게 물어볼 것은 답변 맨 끝에 모아서 묻는다.
- 결과는 표로 정리하는 것을 좋아한다.
- 공개 파일에는 실명 대신 가명 '욍읭'만 쓴다. 내 PC 폴더 경로(실명이 들어 있음)도 공개 파일에 쓰지 않는다.
- 블로그 글 말투는 `1주차 결과물/블로그/guide/style_guide.md`를 따른다.

**저장소 규칙 (저장소 맨 위 CLAUDE.md와 같음)**
- 저장소는 Public이라 누구나 볼 수 있다.
- 비밀번호, API 키, 토큰, .env, 개인정보, 고객 자료는 쓰거나 커밋하지 않는다.
- 작업은 이 폴더(`hys0870-llm-academy/`) 안에서만 한다.
- 커밋·push 전에 민감정보를 검사해 보고하고, 사용자 확인 후 진행한다.
- 작업을 마치면 이 HANDOFF.md를 갱신한다.

**건드리면 안 되는 파일**
- 저장소 맨 위 `readme.md` (원본 강의 안내)
- 저장소 맨 위 날짜별 폴더 3개 (`2026-10-29_제로이드-제안서`, `2026-10-30_본투윈-제안서`, `2026-11-02_본투윈-제안서-v19_블로그-에이전트팀`) — 그대로 두기로 결정
- 다른 수강생 폴더
- 저장소 맨 위 `CLAUDE.md`, `.gitignore`는 사용자가 요청할 때만 수정
