# 사용법

## 처음 한 번
1. 이 폴더(`블로그에이전트팀`)를 VS Code로 열고 Claude Code를 실행합니다. Cowork에서 이 폴더를 연결해도 됩니다.
2. 이미지 생성용 설치 (터미널):
   ```
   pip install playwright
   playwright install chromium
   ```

## 글 하나 쓰기
1. `input/_메모템플릿.md`를 복사해 `input/코닥어패럴.md`처럼 저장하고 아는 만큼 채웁니다.
   - **직접 경험 메모**에 적은 것만 "입어봤다"고 씁니다.
   - 사진은 `input/photos/`에 넣고 파일명을 메모에 적습니다 (대표 사진은 파일명에 `대표`).
2. Claude에게 한 줄로 요청합니다.
   > `input/코닥어패럴.md 메모로 블로그 글 써줘`
3. `output/<날짜_주제>/final.html`을 브라우저로 열어 검수합니다.
   - 회색 점선 박스 = 내가 사진을 넣을 자리
   - 노란 강조 = 확인이 필요한 정보
4. 이미지 파일을 모읍니다 (아래 「이미지 넣는 법」).
5. 네이버 에디터에 본문을 붙여 넣고, 사진·지도를 넣고 발행합니다.

## 이미지 넣는 법 (네이버 블로그)
네이버 에디터는 **인터넷 주소(링크)로 된 이미지를 넣을 수 없고, 내 컴퓨터의 파일을 올려야** 합니다.
글에 들어가는 이미지는 세 종류입니다.

| 종류 | 어디 있나 |
|---|---|
| 썸네일·비교표·코디 카드 | `output/<글폴더>/images/` (이미 파일) |
| 유니클로 공식 사진 | 공식몰 링크 |
| AI 코디 사진 | Figma 링크 (생성 7일 뒤 만료) + 내 Figma 파일 |

1. **글을 쓸 때 팀이 자동으로 처리합니다.** image-maker가 공식몰·AI 사진을 내려받아 글에 넣고, assembler가
   - 사진까지 들어간 완성본 `final.html`
   - 네이버에 올릴 사진을 순서대로 모은 `upload/` 폴더 (`01.png`, `02.jpg` … + `업로드순서.txt`)
   를 만듭니다. 이미 만든 글에 사진만 다시 넣고 싶으면 Claude에게 **"output/<글폴더> 이미지 넣어줘"** 라고 하면 됩니다.
2. 네이버 글쓰기 → 상단 **[사진]** 버튼 → `upload` 폴더에서 파일을 **전부 선택**해 한 번에 올립니다.
   (또는 탐색기에서 파일들을 에디터로 끌어다 놓아도 됩니다.)
3. 올라간 사진을 `final.html` 미리보기와 같은 위치로 끌어서 옮기고, `업로드순서.txt`의 캡션을 사진 설명에 붙여 넣습니다.
   - 공식몰 사진: `이미지 출처: 유니클로 공식 온라인스토어` 유지
   - AI 사진: `AI로 생성한 코디 예시 이미지입니다` 유지
4. 첫 번째 이미지(썸네일)를 **대표 이미지**로 지정합니다 (사진 클릭 → 대표).

**팁**
- 본문과 사진을 한꺼번에 넣고 싶으면, 본문을 먼저 붙여 넣고 사진을 하나씩 해당 위치에 놓는 편이 순서가 꼬이지 않습니다.
- AI 사진 링크가 만료됐다면 Figma 파일 「블로그 AI 코디 이미지 — 유니클로 3D니트」에서 이미지 선택 → 오른쪽 아래 **Export → PNG**로 저장해 `upload` 폴더에 넣으세요.
