## 1. 말투 (가장 중요)

### 기본 어미
- 기본은 **합니다체**: `~입니다`, `~습니다`, `~했습니다`
- 부드러운 연결과 마무리 어미를 섞는다. 실제로 자주 쓰는 어미:
  - `~는데요.` → 다음 문단이나 사진으로 넘어가기 전의 연결 (가장 많이 씀)
  - `~더라고요.` / `~겠더라고요.` → 직접 보거나 입어본 소감
  - `~것 같습니다.` / `~좋아 보였습니다.` → 단정하지 않는 평가
  - `~좋겠습니다.` / `~살펴볼 만합니다.` → 추천과 제안
  - `~거든요.` / `~죠.` / `~겠죠.` → 이유 설명, 가벼운 공감 (가끔)
- 같은 어미가 3문장 이상 연속되지 않게 섞는다.

### 쓰지 않는 것
- 이모지, `ㅎㅎ`, `ㅋㅋ`, `!!`, `~~` 같은 장식
- 느낌표는 거의 쓰지 않는다 (글 전체에서 0~1개)
- "강력 추천", "인생템", "미쳤다", "역대급", "무조건" 같은 과장 표현
- "여러분!", "꿀팁 대방출" 같은 호객형 표현
- AI 티 나는 표현: "~에 대해 알아보겠습니다", "결론적으로", "다양한 측면에서", "~라고 할 수 있습니다" 반복, "첫째/둘째/셋째" 나열
- 장점만 늘어놓는 홍보문. 대신 "~를 중요하게 본다면" 식으로 조건을 붙인다.

### 평가하는 방식
- 단정보다 완곡하게: "따뜻합니다" → "쌀쌀한 날씨에 손이 갈 만한 아이템인데요."
- 근거 + 활용으로 말한다: 스펙(소재, 충전재 비율) → 그래서 어떤 상황에 좋은지 → 어떻게 입을지
- 개인 경험은 짧게, 과장 없이: "제가 입은 라이트 그레이", "옐로우가 눈에 들어와 착용을 해봤었는데요."

## 2. 줄바꿈과 문단 (네이버 모바일 기준)

- **한 줄은 15~25자 정도에서 끊는다.** 의미 단위(구·절)에서 줄을 바꾼다.
- **2~3줄이 한 문단**이고, 문단 사이에는 빈 줄을 하나 둔다.
- 사진 1장마다 문단 1~2개(2~5줄)가 붙는 리듬이다.
- 예시:

```
날씨가 쌀쌀해지면 자연스럽게
가볍게 걸치기 좋은 아우터부터 찾게 되는데요.

평소 편하게 입는 데님이나 면바지에도 잘 어울리고,
조금 더 추워졌을 때는 레이어드해서 입을 수 있는
아이템이라면 활용도가 더욱 높겠죠.
```

## 5. 소제목 규칙

- 네이버 에디터의 **인용구(따옴표) 블록**으로 소제목을 단다. 마크다운에서는 `> 소제목`으로 쓴다.
- 형태: **수식어구 + 명사**. 짧은 한 줄.
  - 좋은 예: `홍대에서 만나는 코닥 서울 쇼룸`, `일상과 여행을 연결하는 컬러라마 시리즈`
  - 제품 소제목은 제품명 그대로: `컬러라마 경량 구스 다운 자켓`
- 마지막 소제목은 항상 `마치며`.
- SEO상 필요하면 일부 소제목을 질문형으로 바꿀 수 있다 (예: `경량패딩, 구스 다운과 웜볼 중 무엇이 좋을까`). 단, 글 전체에서 1~2개만.

- 가격은 `가격 : 299,000원` (콜론 앞뒤 띄어쓰기, 천 단위 쉼표)

- 사진 캡션은 짧은 명사구: `1층 매장 전경`, `2층 매장 전경`

## 8. 제목 패턴

두 가지를 번갈아 쓴다.
1. **키워드 나열형**: `브랜드 + 성별 + 카테고리&카테고리 + 장소 + 매장 + 쇼핑리스트/코디 추천`
   - 예: `코닥어패럴 남자 경량패딩&플리스 홍대 코닥 서울 쇼룸 쇼핑리스트 추천`
   - 예: `TOPTEN10 텐텐데이 탑텐플러피 남자뽀글이 겨울 후리스 자켓 추천`
2. **모델명 + 쉼표 + 한 줄 포인트**: 시계·단일 제품용
   - 예: `IWC 인제니어 40 IW328903, 아쿠아 다이얼로 만나는 젠타 디자인`
   - 예: `론진 레전드 다이버 39MM, 300만원대 헤리티지 다이버 시계`

## 9. 단일 제품 착용·코디형 글 (무브스포츠·에디션 글에서 추출)

> 마치며
  제품 한 줄 정의 → 착용 컬러·사이즈·코디 요약 → "~를 찾고 있다면 ~도 함께 살펴보시면 좋겠습니다."

| 여밈 활용 | 열어 입으면 ~가 드러나면서 조금 더 경쾌하게, 여며 입으면 ~를 중심으로 보여줄 수 있어요. |
| 공감 | ~할 때 입는 옷은 보온성만큼 쾌적함도 신경 쓰게 되잖아요. |

- 이 유형은 해요체(`~봤어요`, `~구성이에요`, `~라고 해요`) 비중이 조금 더 높다. 합니다체 7 : 해요체 3 정도.
- 페르소나 키워드(남편룩, 출근룩, 데일리룩 등)를 제목·코디 소제목·해시태그에 함께 쓴다.
- 해시태그는 6~12개. 코디 아이템 태그(#청바지코디 #더비슈즈코디)와 시즌 코디 태그(#남자가을코디)를 포함한다.

## 9-1. 정보 전달형 글 (기본값 — 직접 입어보지 않은 신상·시즌 정리)

메모의 글 유형이 `정보 전달형`이거나 직접 경험 메모가 없으면 이 방식으로 쓴다.
"입어봤다"가 아니라 **"이런 제품이 나왔다 → 이런 특징이 있다 → 이렇게 입으면 좋겠다"**의 흐름이다.

- 도입: 계절 공감 → "이번에 ○○가 ○월 ○일 ○○를 선보였습니다." → "오늘은 ~를 정리하고, ~코디까지 함께 소개해볼게요."
- 제품 정보 블록: `제품명 / 가격 / 컬러 / 사이즈` (착용 컬러·착용 사이즈는 쓰지 않는다)
- 특징 설명 어미: `~이 특징입니다`, `~라고 해요`, `~한 구성이에요`, `~점도 눈에 들어옵니다`
- 활용 제안 어미: `~하기 좋겠습니다`, `~를 추천해요`, `~해보세요`, `~면 좋겠습니다`, `~가 무난하겠습니다`
- 코디 섹션: "매치했습니다(과거)" 대신 "매치하면 ~이 됩니다 / ~를 더해보세요 / ~조합을 추천해요"
- 사진: 공식몰 제품·모델 컷과 AI 코디 예시를 쓰고, 캡션에 출처·AI 표기를 붙인다. "제가 입은" 같은 표현 금지.
- 사이즈 팁: 공식 정보(핏, 사이즈 구성, 온라인 전용 여부) + 일반적인 고르는 법만. 체감 착용감은 쓰지 않는다.
- 제목: `브랜드 + 카테고리 + 시즌 신상 + 몇 종 정리, + 코디 추천` (예: 유니클로 니트 26FW 신상 3D니트 4종 정리, 남자 니트 코디 추천)

## 10. 경험 관련 절대 규칙

- 사용자가 메모로 주지 않은 **착용감, 사이즈감, 직접 입어본 경험은 지어내지 않는다.**
  (공정위 추천·보증 심사지침상 실제 경험과 다른 후기는 부당광고가 될 수 있다.)
- 경험 정보가 없으면 "~해 보였습니다", "~할 수 있을 것 같습니다"처럼 관찰·추론 톤으로 쓰거나 `[확인 필요: 착용 소감]`으로 비워 둔다.
