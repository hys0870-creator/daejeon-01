# 이미지 가이드 — 패션 블로그용

> image-maker 에이전트가 따르는 규칙이다.
> 이 블로그는 **직접 찍은 사진이 주인공**이다. 에이전트가 만드는 이미지는 사진을 보조하는 "정보 카드"뿐이다.
> 영상 예시의 어두운 테크 톤 대신, 패션 블로그에 맞는 밝고 깔끔한 톤을 쓴다.

---

## 1. 두 종류의 이미지 자리

| 표시 | 누가 채우나 | 설명 |
|---|---|---|
| `[사진: 설명]` | **사용자** | 직접 찍은 사진. 에이전트는 만들지 않고 그대로 둔다. 예: `[사진: 컬러라마 경량 구스 다운 자켓 라이트 그레이 착용 정면]` |
| `[이미지: 템플릿명 / 내용]` | **image-maker** | HTML·CSS로 만들어 PNG로 저장 |
| `[공식이미지: 제품명 / 컬러]` | **image-maker** | 메모에서 허용했을 때만. 리서치에 있는 공식몰 이미지 URL을 연결 |
| `[AI코디: 코디 설명]` | **사용자(외부 AI 도구)** | image-maker가 프롬프트를 `ai_prompts.md`에 써 두고, 사용자가 Gemini·ChatGPT 등으로 생성해 넣는다 |

사용자가 `input/` 메모에 사진 파일명을 적어 두었고 그 파일이 `input/photos/`에 있으면, `[사진: ...]`을 해당 파일 경로로 바꿔 넣는다.

### 공식몰 제품 이미지 사용 규칙
- 메모에 "공식 이미지 사용"이 있을 때만 쓴다. 기본은 직접 찍은 사진.
- 리서치에 기록된 공식 URL로 넣은 뒤 `scripts/download_images.py`로 **원본 그대로** 내려받아 글에 넣는다. 자르기·글자 넣기 등 재가공은 하지 않는다.
- 캡션에 반드시 `이미지 출처: ○○ 공식 온라인스토어`를 붙인다.
- 제품 사진은 브랜드의 저작물이다. 네이버 발행 전에는 브랜드의 사용 허락(협찬 계약서·보도자료 이용 조건)을 확인하거나 직접 찍은 사진으로 바꾼다. 남의 이미지 재사용은 저작권 문제와 함께 SEO상 유사 이미지 감점 원인이다.

### AI 코디 이미지 규칙
- Figma 커넥터(`generate_image`)가 연결되어 있으면 image-maker가 직접 생성한다. 사용자 Figma 파일에 저장되며 Figma AI 크레딧을 쓴다. 같은 글의 코디 이미지는 같은 체형 묘사를 써서 인물이 일관되게 보이게 하고, 체형이 다르게 나오면 같은 노드에 다시 생성한다.
- 커넥터가 없으면 **프롬프트만** `ai_prompts.md`에 쓰고 사용자가 외부 도구로 만든다.
- 프롬프트에는 착용자 체형(메모 기준), 아이템별 색·소재, 배경, 구도(전신·정면·자연광)를 넣는다. 실존 인물·브랜드 로고는 넣지 않는다.
- 본문 캡션에 `AI로 생성한 코디 예시 이미지입니다`를 반드시 붙인다. 실제 착용 사진처럼 보이게 쓰지 않는다.
- 같은 코디를 정보 카드로도 보여주고 싶으면 `coord-card` 템플릿(아래 ⑤)을 쓴다.

## 2. 공통 디자인 규칙

- **폭 966px** (네이버 블로그 본문 이미지 최대 폭). 썸네일만 1080×1080.
- 배경: 따뜻한 오프화이트 `#F7F4EF`
- 본문 텍스트: 차콜 `#2B2B2B`, 보조 텍스트 `#7A746C`
- 포인트 컬러: 기본 `#1F3A5F`(네이비). 글에 브랜드 대표 컬러가 있으면 그 색 1가지만 포인트로 써도 된다 (예: 코닥 옐로우 `#F5B700`). **포인트 컬러는 한 이미지에 1가지만.**
- 구분선: `#DDD6CC` 1px
- 폰트: `Pretendard` (CDN) → 없으면 `"Malgun Gothic", "Apple SD Gothic Neo", sans-serif`
  - 제목 700, 본문 400~500
- 여백: 바깥 여백 최소 56px, 요소 사이 24px 이상
- 이미지 안 텍스트는 **짧게**. 한 줄 20자 이내, 문장 대신 명사구.
- 우측 하단에 작게 `욍읭` 워터마크 (12~14px, 보조 텍스트 색)
- 그림자·그라데이션·아이콘 남발 금지. 미니멀한 매거진 느낌.

## 3. 템플릿 5종 (이 중에서만 고른다)

### ① 썸네일 `thumbnail` — 1080×1080
- 대표 사진이 있으면 사진을 배경으로 꽉 채우고 아래 1/3에 반투명 오프화이트 띠 + 제목.
- 사진이 없으면 오프화이트 배경 + 큰 제목 2줄 + 작은 부제(브랜드/장소) + 포인트 컬러 라인.
- 제목은 글 제목에서 핵심 키워드만 뽑아 2줄 이내 (예: `코닥어패럴 / 경량패딩 & 플리스`).

### ② 제품 정보 카드 `product-card` — 966×(자동, 최대 700)
- 쓰는 곳: 제품이 3개 이상인 글에서 **한 라인/시리즈를 요약**할 때, 또는 제품 하나의 스펙을 정리할 때.
- 구성: 상단 작은 라벨(시리즈명) → 제품명(크게) → 가격 → 컬러 칩(실제 색상 원 + 이름) → 핵심 스펙 2~4줄(소재, 충전재 비율 등)
- 컬러 칩 색상값은 제품 사진이나 컬러명에서 근사값으로 고른다.

### ③ 비교표 `compare-table` — 966×(자동)
- 쓰는 곳: 두 개 이상 제품을 비교할 때. 주로 `마치며` 직전이나 직후 1장.
- 열: 제품명 / 가격 / 충전재·소재 / 이런 분께
- 4행 이하, 셀 텍스트 15자 이하.

### ④ 매장 정보 카드 `store-card` — 966×(자동)
- 쓰는 곳: 매장·팝업 방문 글. 지도 대신 쓰지 않고, 네이버 지도 삽입은 사용자가 에디터에서 한다.
- 구성: 매장명 / 주소 / 영업시간 / (선택) 층별 구성 한 줄씩

### ⑤ 코디 카드 `coord-card` — 966×(자동)
- 쓰는 곳: 코디 팁 섹션. 코디 하나를 "아이템 조합표"로 보여준다.
- 구성: 상단 라벨(코디 이름, 예: `출근룩`) → 아이템 3~4줄 (부위 / 아이템 / 컬러 칩) → 하단 한 줄 포인트(20자 이내)
- 여러 코디를 한 장에 2개까지 나란히 넣을 수 있다.

> 다른 템플릿이 필요하면 이 파일에 추가한 뒤 사용한다. 즉흥적으로 새 스타일을 만들지 않는다.

---

## 4. 수량

- 썸네일 1장 + 정보 이미지 **1~3장**. 글 전체에서 생성 이미지가 4장을 넘지 않는다 (공식 이미지·AI 코디 자리는 제외).
- 사진 자리 `[사진: ...]`은 개수 제한 없음 (writer가 정한 대로).

---

## 5. 제작 방법

1. 템플릿마다 HTML 파일을 `output/<글폴더>/images/src/` 에 만든다. CSS는 HTML 안에 인라인.
2. 렌더링:
   ```
   python scripts/render_image.py <html경로> <png경로> --width 966
   python scripts/render_image.py <html경로> <png경로> --width 1080 --height 1080
   ```
   (높이를 생략하면 내용 높이에 맞춰 자른다. 2배 해상도로 저장된다.)
3. 저장한 PNG를 **다시 열어서 직접 확인**한다 (Read 도구로 이미지 보기).
4. 아래 중 하나라도 있으면 HTML을 고쳐 다시 렌더링한다. 문제가 없어질 때까지 반복 (최대 3회):
   - 텍스트가 잘리거나 넘침, 줄바꿈이 어색함
   - 여백이 한쪽으로 쏠림, 요소 정렬 틀어짐
   - 글자가 배경과 대비가 약해 안 읽힘
   - 한글 폰트가 깨짐(□)
   - 정보가 research 내용과 다름 (가격, 컬러명)
